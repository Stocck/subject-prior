# Литература к диплому — отбор

> [!info] Черновик Claude, 2026-09-24
> 70 кандидатов под аннотацию диплома: ED-блок из [[Petrosyan2022]] сохраняется, BiLSTM заменяется причинной TCN. Колонка «Полезность» пустая — её заполняешь ты. Описания фактические (что за работа и к какому утверждению аннотации относится), оценок в них нет. Выходные данные сверены по страницам издателей, PubMed и arXiv; где DOI подтвердить не удалось, стоит ссылка на страницу статьи.

**Шкала:** `2` - читать целиком, `1` - выборочно, `0` — только для ссылки в тексте, `-1` - мимо.

**Колонка BibTeX:** ✅ — запись с ключом есть в `Литература к диплому.bib` (та же папка); ⚠️ — запись есть, но названных полей в ней нет, потому что сверить их не удалось. Пусто — полезность ещё не проставлена.

Группы идут по утверждениям аннотации, внутри группы — по году. Номер сквозной, чтобы ссылаться коротко: «№ 17».

## Что не вошло (решение Claude, можно вернуть)

Границы отбора проведены по аннотации, и три пласта оставлены за ними сознательно. Декодирование воображаемой речи по скальповой ЭЭГ — работ много, но это другая модальность и другой уровень сигнала. Foundation-модели для iEEG с самообучением на больших корпусах — другая постановка задачи; как представитель оставлен Du-IN (№ 8). Общие обзоры BCI из списка литературы [[Petrosyan2022]] — к утверждениям аннотации напрямую не относятся.
